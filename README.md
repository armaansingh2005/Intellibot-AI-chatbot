# 🤖 IntelliBot AI — Intelligent Customer Support Chatbot

**IntelliBot AI** is an AI-powered customer support chatbot designed to automate frequently asked questions (FAQs), understand user queries using Natural Language Processing (NLP), and deliver relevant responses through an interactive web interface.

Built using Python, Flask, and Machine Learning, IntelliBot AI combines intent recognition, intelligent FAQ retrieval, contextual conversations, and persistent chat history to provide a smarter and more efficient customer support experience.

The project also features an administrative dashboard for monitoring chatbot interactions, analyzing conversation statistics, and managing customer support activities.

## ✨ Key Features

* 🧠 **AI-Powered Intent Recognition:** Uses TF-IDF and machine learning models to understand and classify user queries.
* 💬 **Intelligent FAQ Responses:** Retrieves relevant answers from a configurable FAQ knowledge base.
* 🔄 **Context-Aware Conversations:** Supports lightweight conversational context for more natural interactions.
* 🛡️ **Smart Fallback Handling:** Provides appropriate fallback responses when a query cannot be confidently understood.
* 📝 **Conversation History:** Stores chat interactions using SQLite for persistent records.
* 📊 **Admin Analytics Dashboard:** Visualizes chatbot usage and conversation statistics.
* 🔐 **Admin Authentication:** Provides a protected administrative interface.
* 🌐 **Responsive Web Interface:** Offers an interactive chat experience using HTML, CSS, and JavaScript.
* 🔌 **REST API Integration:** Supports communication between the chatbot backend and frontend.
* 📤 **Data Export:** Supports CSV export for analyzing conversation records.

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Backend Framework:** Flask
* **Artificial Intelligence:** Natural Language Processing (NLP) and Machine Learning
* **ML Libraries:** Scikit-learn, NLTK
* **Machine Learning Techniques:** TF-IDF Vectorization and Logistic Regression
* **Database:** SQLite
* **ORM:** SQLAlchemy
* **Frontend:** HTML5, CSS3, JavaScript
* **Data Visualization:** Chart.js
* **Development Environment:** Visual Studio Code

## 🎯 Project Objective

The primary objective of IntelliBot AI is to demonstrate how Natural Language Processing and Machine Learning can automate customer support by understanding user queries, identifying their intent, retrieving relevant answers, and maintaining conversation records.

The project aims to reduce repetitive manual support tasks, improve response consistency, and provide a foundation for building intelligent customer service applications.
