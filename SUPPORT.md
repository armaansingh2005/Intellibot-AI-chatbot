# Support

IntelliBot AI is an educational portfolio project and does not provide a hosted chatbot or production support service.

- For reproducible defects, use the GitHub bug-report issue template.
- For proposed improvements, use the feature-request issue template.
- For security concerns, follow [SECURITY.md](SECURITY.md) and do not post exploit details publicly.
- For setup questions, check the [README troubleshooting guide](README.md#18-troubleshooting).

Do not post credentials, private customer data, or sensitive logs in public issues. No response-time or maintenance guarantee is provided.
