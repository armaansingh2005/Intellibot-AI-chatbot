# Security policy

IntelliBot AI is an educational demonstration, not a production-ready customer-support service. Do not submit real customer data, credentials, or other sensitive information.

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in a public issue. Contact the repository owner privately through GitHub, or use GitHub's private vulnerability reporting feature if it is enabled for the repository. Include the affected component, impact, and concise reproduction details. Avoid including real secrets or personal data.

There is no guaranteed response time or supported release schedule for this portfolio project. Do not assume a report is resolved until the owner confirms it.

## Supported versions

Only the current repository version is considered for review. No production service or security-update SLA is provided.

## Deployment reminder

Before any deployment, configure a strong stable `SECRET_KEY`, HTTPS, an appropriate database and rate-limit backend, dependency updates, backups, access controls, and a privacy/retention policy. The bundled sample FAQ data is fictional.
